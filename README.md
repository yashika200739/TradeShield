# TradeShield

TradeShield is a JavaFX desktop application for safely simulating and reviewing stock orders.

## Stage 1

This first stage provides the Maven project structure and a static fintech dashboard. It does not place orders or implement risk rules yet.

## Run the application

Open PowerShell in this folder and run:

```powershell
mvn javafx:run
```

Use `mvn clean compile` when you only want to compile the code.
